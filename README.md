# End-to-End Data Pipeline: CSV to SQL Server, Microsoft Fabric & Power BI

This project demonstrates an end-to-end data integration and analytics workflow, from ingesting raw CSV files into SQL Server to building a Lakehouse in Microsoft Fabric and developing an interactive Power BI report.

The goal is to showcase key data engineering and business intelligence concepts, including data ingestion, data integration, data storage, and data visualization.

### Project Workflow
- **Data Ingestion:** Import data from CSV files into SQL Server.
- **Data Integration:** Extract data from SQL Server and load it into a Microsoft Fabric Lakehouse.
- **Data Storage:** Organize and store data in the Lakehouse to support analytics.
- **Data Visualization:** Connect Power BI to the data platform and build an interactive report to explore insights and support data-driven decision-making.

### Technologies Used
- Microsoft SQL Server
- Microsoft Fabric Lakehouse
- Microsoft Power BI
- CSV files

### Key Skills Demonstrated
- Data ingestion and integration
- SQL Server data management
- Lakehouse architecture
- Data pipeline development
- Business Intelligence and data visualization
- End-to-end analytics workflow
